# 体测成绩分析 📊

体育老师的体测数据处理器：学生原始成绩 CSV 丢进来，自动算好
**单项得分、总分、等级**，并生成能直接拿去开班会/交年级组的**班级报告**，
还支持**两次体测对比**和**多班批量处理**。纯 Python 标准库，零依赖，离线可用。

## 快速开始

```bash
python fitness_analyzer.py --demo            # 内置示例：一个班两次体测 + 对比报告
python fitness_analyzer.py 我的班级.csv        # 单个班
python fitness_analyzer.py 年级文件夹/          # 批量：文件夹里每个 CSV 一个班
python fitness_analyzer.py 期末.csv --compare 期初.csv   # 两次对比（--compare 是旧一次）
python run_tests.py                          # 11 项自检
```

## 输入格式

CSV 列：`学号,姓名,性别,年级，身高cm，体重kg`（自动算 BMI），其余列名与项目名一致即可：
肺活量、50米跑、坐位体前屈、立定跳远、1分钟跳绳、1分钟仰卧起坐、引体向上、50米x8往返跑、800米跑、1000米跑。
耐力跑成绩写 `245`、`4:05`、`4'05"`、`4分05秒` 都认；缺测的项目留空，会自动按已测项目折算总分。

## 输出

每个班一份：

- `*-scores.csv`：每人各单项得分、BMI 值、总分、等级（优秀 ≥90 / 良好 ≥80 / 及格 ≥60 / 不及格 <60）
- `*-report.md`：平均分、等级分布、及格率与优秀率、各项目平均分（弱项在前，带条形图）、
  不及格学生名单及其最弱两项、班级前三
- 对比模式额外出 `compare-report.md`：全班平均变化、各项目平均分变化、进步最大 5 人、退步关注名单

计分方法：按标准表断点做线性插值（比查表跳档更平滑），权重按年级配置在标准表 JSON 中；
总分按已测项目权重归一，缺测不误伤。

## 关于评分表（重要）

`data/standards_sample.json` 是依据《国家学生体质健康标准》公开框架**节选整理的示例表**
（覆盖五年级、初一两个年级段），数值可能与最新官方文件有出入。
**正式上报前，请务必对照官方最新标准核对或替换这个 JSON**——工具的计分、报告、对比逻辑都不用改。
替换时保持结构不变即可：`年级 → 性别 → 项目 → [[成绩, 分值], ...]`，BMI 用 bands 分档，权重单独一张表。
